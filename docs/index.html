Prefilling-dLLM

Predictive Prefilling for Long-Context Inference in Diffusion Language Models

The first dLLM inference engine with native prefill–decode disaggregation.

Jing Xiong · Qi Han · Shansan Gong · Yunta Hsieh · Chengyue Wu · Chaofan Tao · Chenyang Zhao · Ngai Wong

Paper PDF Code

Native PD disaggregation for dLLMs

Prefilling-dLLM separates prefix computation from iterative denoising. Prefill workers partition and encode long contexts once, then expose transferable KV snapshots. Decode workers reuse the selected sparse prefix KV throughout generation instead of re-encoding the full prefix at every step.

Prefill → chunk the prefix, build KV once, score relevance, select top-K chunks and tokens.
Transfer → move stable paged-KV snapshots across the explicit PD boundary.
Decode → iteratively denoise the response against the selected non-contiguous prefix KV.

Highlights

  • Training-free integration with existing diffusion language models.
  • Native prefill and decode execution stages with transferable KV snapshots.
  • Predictive inter-chunk selection and optional intra-chunk token sparsity.
  • Non-contiguous paged-KV attention for sparse long-context decoding.
  • 9.1–28.0× speedup at 8K–32K contexts in the paper's experiments.
